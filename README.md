# FlyFund Arena

미국 빅테크 4종목과 SK하이닉스를 대상으로 초파리 신경망 실험을 보여주는 **모의투자 전용** 대시보드입니다.

종목: `NVDA`, `000660.KS`, `AAPL`, `MSFT`, `AMZN`

## 현재 상태

- 작동하는 일봉 수집기와 로컬 캐시
- 다음 거래일 시가에만 체결하는 재현 가능한 백테스트
- Fly+Risk, Pure Fly, 무작위 신경망, Buy & Hold, 이동평균, 랜덤 비교
- 날짜 재생, 감각 차트, 뇌 영역 활성도, 개별 투표, 감사 로그 대시보드
- 한국어/영어 전환과 지표·뇌 영역별 도움말
- 휴장일 평가액 이월, 분할조정 OHLC, 원/달러 환율, 모든 전략의 동일 수수료 처리
- 시장 입력→네 마리 투표→합의→비중→다음 장 손익을 보여주는 의사결정 리플레이
- 한 마리씩 감각 입력→보상·기억→뇌 활성→매수·매도 판독 경쟁→최종 행동을 추적하는 판단 현미경
- 설탕 보상·불쾌 자극의 연합학습 애니메이션과 접근/회피→좌/우 운동→매수/매도 라벨을 분리해 보여주는 행동 번역 실험실
- 선택 날짜의 5종목 보유 수량·주식평가액·현금·실제 보유 비중과 다음 거래일 목표를 구분한 Fly+Risk 모의 장부
- 1년·3년·5년·전체 또는 사용자 지정 기간을 선택하고 첫 평가액을 $10,000으로 재기준화하는 성과 차트
- 상단 기간 선택의 기본값은 최신 거래일 기준 1년이며 데이터 업데이트 후에도 새 최신일에 맞춰 자동 이동
- 상위 활성 영역을 대비 강화한 3D 뇌와 좌·우 DNp20 판독 뉴런·DNpe017 운동 게이트 경로
- 시장 캔들·6개 감각 벡터·네 초파리 투표를 한 열에 묶고 3D 뇌를 독립 열로 둔 판단 작업공간
- 초파리별 단독 신호 성과를 겨루는 Fly Cup과 선택일의 반대 비중을 비교하는 평행세계 카드
- 서버 실행 중 6시간마다 갱신 및 시작 시 누락분 보충
- 실제 주문 코드 없음
- Windows에서 Stonkfly C++17 커널 DLL 빌드 및 전체 MaleCNS 실행 검증

오늘의 종목별 투표는 공식 MaleCNS v1.0 전체 그래프와 Stonkfly C++ 커널로 계산됩니다. 네 초파리는 각각 40일·70일·100일·130일 가격 시야를 봅니다. 장기간 리그 수익곡선은 계산비용을 줄이기 위한 `fly-proxy-v1` 백테스트이며 화면에도 별도로 표시됩니다.

판단 현미경은 이 차이를 유지합니다. 최신 MaleCNS 실행은 `learning=false`이므로 보상이 실제 뇌에 주입되지 않았다고 표시하고 좌·우 DNp20 발화율과 운동 게이트를 보여줍니다. 과거 프록시 재생에서만 직전 계좌 수익으로 기억이 갱신되는 학습 루프를 시각화합니다.

## 실행

Node.js 20 이상만 필요합니다.

```powershell
npm.cmd test
npm.cmd start
```

브라우저에서 <http://127.0.0.1:4173>을 엽니다.

## 무료 웹 배포

Cloudflare Pages에는 정적 대시보드만 배포하고, 시세와 MaleCNS 계산은 GitHub Actions가 한국장·미국장 마감 후 실행합니다. 브라우저가 배포된 시장 스냅샷으로 시드별 프록시 백테스트를 계산하므로 공개 사이트에서도 실험 시드를 바꿀 수 있습니다.

1. 이 프로젝트를 GitHub 저장소에 올립니다.
2. Cloudflare Pages에서 저장소를 연결합니다.
3. 빌드 명령을 `npm run build`, 출력 폴더를 `dist`로 설정합니다.
4. GitHub 저장소의 Actions를 활성화합니다. `Refresh market and MaleCNS snapshot` 작업은 평일 `16:17 KST`와 `07:17 KST` 무렵 실행되며 수동 실행도 가능합니다.

로그인 비밀번호나 개인 토큰을 다른 사람에게 전달하지 마세요. GitHub와 Cloudflare의 공식 OAuth 화면에서만 접근을 승인합니다. 첫 자동 실행은 검증된 MaleCNS 데이터를 내려받아 변환하므로 이후 실행보다 오래 걸릴 수 있습니다.

시세만 한 번 갱신하려면:

```powershell
npm.cmd run update
```

네트워크를 사용할 수 없으면 데모 데이터로 시작하며, 화면 상단에 그 사실을 표시합니다. Yahoo Finance의 공개 차트 엔드포인트는 비공식 인터페이스이므로 운영 환경에서는 라이선스가 명확한 공급자로 교체해야 합니다.

## Windows C++ 커널

작업 PC에는 WinLibs GCC 16.1.0이 `C:\tools\flyfund-winlibs`에 설치되어 있습니다. 프로젝트 경로의 한글 문자를 MinGW가 잘못 처리할 수 있어 소스를 영문 임시 경로에 복사해 컴파일합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-kernel.ps1
```

출력: `C:\tools\flyfund-build\memory.dll`

공식 MaleCNS 연결 데이터(다운로드 약 1.1GB)를 준비하고 10ms 스모크 테스트를 실행하려면:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\prepare-malecns.ps1
$env:PYTHONPATH="$PWD\vendor"
.\.venv\Scripts\python.exe .\scripts\malecns-smoke.py
```

데이터는 `data/malecns`에 저장되고 Git에는 포함되지 않습니다. 원본과 변환 배열은 업스트림 잠금 파일의 SHA-256으로 검증됩니다.

## 자동 업데이트

서버가 계속 켜져 있으면 시작 시와 6시간마다 일봉과 MaleCNS 결정을 갱신합니다. 컴퓨터가 꺼져 있어도 다음 시작 시 최신 5년 데이터를 다시 받아 누락분을 보충합니다.

현재 PC에는 다음 스크립트로 한국장 마감 후 `16:10 KST`, 미국장 마감 후 `07:10 KST` 예약 작업을 설치할 수 있습니다. 작업을 놓치면 Windows의 `StartWhenAvailable` 설정으로 다음 로그인·부팅 후 실행됩니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-daily-task.ps1
npm.cmd run daily
```

## 실험 규칙

- 신호는 당일 종가까지의 데이터만 사용합니다.
- 판단은 다음 거래일 시가에 실행됩니다.
- 공매도와 레버리지는 사용하지 않습니다.
- 거래비용 0.1%를 FlyFund와 모든 비교 전략에 동일하게 반영합니다.
- SK하이닉스와 미국 종목은 독립된 $2,000 슬리브로 계산하고, 한국장·미국장 휴장일에는 각 슬리브의 직전 평가액을 유지합니다.
- SK하이닉스의 원화 평가액은 일별 원/달러 환율로 달러 환산합니다.
- 초기 모의자산은 $10,000이며 종목별 $2,000 슬리브로 시작합니다.
- `Fly Signal`은 다수결을 5%·55%·95% 비중으로 실행하고, `Fly+Risk`는 3일 합의·100일 추세·20일 변동성으로 5%부터 95%까지 10단계 비중을 선택합니다. 두 전략 모두 전액매수·전액매도를 하지 않습니다.
- 화면의 `현재 보유 비중`은 선택일 종가 기준 주식평가액÷계좌평가액이고, `다음 목표`는 이후 거래일 시가에 적용할 목표값입니다. 둘은 가격 변동과 체결 시점 때문에 다를 수 있습니다.
- 기간 변경은 선택 구간의 첫 평가액을 $10,000으로 비례 재기준화하며, 과거 판단에 필요한 워밍업 신호는 유지합니다.
- 결과는 투자 조언이 아닙니다.
